SEND THIS TO CLIENTS
    https://rayme-car-rental.vercel.app/

It serves the current share card to anyone asking for the first time.

IF WHATSAPP SHOWS AN OLD PREVIEW, SEND THIS ONCE INSTEAD
    https://rayme-car-rental.vercel.app/?v=541f3171

WhatsApp caches a preview against the URL in the message for about a
week and offers no way to purge it, so a link previewed before the card
changed keeps showing the old card. The ?v= value is the card's content
hash, so this is a URL WhatsApp has not cached and it fetches the new
preview. The site ignores the parameter - the page is identical either
way - and canonical/og:url stay on the bare address for search engines.

Regenerate with: python3 build/build.py
